# elyndra.world

一個魔法與科技共生、知識與意識交織的未來世界。在這裡，每一道咒語都能被編寫，每一個念頭都能改變現實。

線上看：<https://weiqi-kids.github.io/elyndra.world/>

## 這個 repo 是什麼

Elyndra 世界觀的網站專案，設定資料與呈現介面都放在這裡。

## 架構

- `src/` — 前端程式碼
- `supabase/` — 資料庫 schema 與遷移
- `e2e/` — Playwright 端對端測試
- `scripts/` — 維護與資料處理腳本

## 技術

Tailwind CSS、PostCSS、Supabase、Playwright、GitHub Actions。環境變數見 `.env.example`。
